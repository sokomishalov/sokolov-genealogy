## Как работать
- Отвечать по-русски, предельно кратко. Исследовать самостоятельно, не спрашивать «продолжать?».
- Новые находки — в реестры `case/*.csv` (python `csv.DictWriter` по существующему заголовку), `case/research-state.md`, вопросы — в `case/questions-for-mom.md`.
- Древо: правится `case/tree.html` (узлы `{ id, g, x, n, s, st, c }`, карточки `<details class="person" id=...>`), затем PDF и сайт.
- PDF: `{ printf '<!doctype html><html lang="ru"><head><meta charset="utf-8">'; cat case/tree.html; } > case/pdf-source/tree-print.html` и headless Chrome `--print-to-pdf=case/Древо-Соколовых-Федосовых-Бедаревых.pdf ...#print`.
- Сайт: `python3 tools/build_site.py` (падает, если в странице утечка: ДНК, даты рождения живых). Новых живых добавлять в `LIVING`/`LIVING_REL`, новых людей — в `PIDS`.
- Промежуточные скрипты и отчёты агентов класть в `work/`; большие скачанные файлы — в `work/raw/` (не в git).
- После каждого обновления: собрать сайт, `git commit` и `git push` в ветку `research` (её пушит GitHub Pages). Пуш — от аккаунта `sokomishalov` (не `sokomishalov-jp`).
