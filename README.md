# Родословная Соколовых, Федосовых и Бедаревых

Древо: https://sokomishalov.github.io/sokolov-genealogy/

- `case/` — дело исследования: реестры (люди, документы, утверждения, связи, журнал поиска), состояние, вопросы маме, старое древо и PDF.
- `work/` — промежуточные материалы: скрипты, отчёты агентов, выгрузки страниц и распознанный текст. Крупные сканы и чужие PDF лежат в `work/raw/` только локально.
- `tools/build_site.py` — собирает сайт `site/` из `case/tree.html` и `case/artifact-register.csv`. Живые люди на сайте только именем.
