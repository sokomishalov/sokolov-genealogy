# Помощник: Клавдия Алексеевна / служба С.С. 1887 (31.10.2026)
Источник: Российский медицинский список (archive.org, OCR), «Вся Москва» (AllMoscow).
- 1912 (л.653): «Соколов Серг. Серг. 87 В. 910. Вет. Упр. 2 воен. отд. Забайкальск. каз. в.» → Акша = управление 2-го воен. отдела ЗабКВ.
- 1913 (л.694): «…Серг. Серг. 87 В. 910. Вет. Ком. М.В.Д. Забайкальск. обл.» (фамилия на пред. строке — сверить скан).
- 1914 (л.787, Уральская обл.): «Соколовъ С. С.—пос. Уильскій».
- 1916 (л.~799): «Соколов Серг. Серг. 87 В. 910. тит. с. Ст. спещал. животнов. Уральск.»
- Цепочка: Москва 1910 → Малоархангельск 1910–11 → Акша 1911–13 → Уил 1913–14 → Уральск 1916.
- Адрес 1913: вероятно «д. Фарбман» (не Дарбман): «Вся Москва 1914» — Дурной пер., 16, владелица Фарбман Мар. Ив.
- Гипотеза: Ермилова Прасковья Алексеевна (Дурной 16, 1914) — возможная сестра Клавдии (слабо).
- Однофамилицы, не сливать: Соколова Клавд. Алексеевна — надзирательница пансиона 2-й муж. гимназии 1886–1910 (р. до 1866); торговка Мариинский рынок 1895.
- Шаги: сканы л.694 (1913), л.~799 (1916); «Вся Москва» 1913, 1915–17 — Дурной 16, Ермиловы; формулярный список ветврача (РГВИА / ГАЗК — ветуправление ЗабКВ 1911–13; ГА ЗКО Уральск 1913–17) — там жена с девичьей фамилией; метрики Уила/Уральска 1913–17 (крещения детей).
