NOTES:

The T81 DAI film 305 contains many miscellaneous items of interest to the
Dobrudscha and Bessarabian researcher. Starting with this file, we will add new
files as we extract DAI data for Dobrudscha.

The user is reminded, that these films as a whole will be added to the DAI film
collection held at GRHS in Bismarck.

It is intended that these films be incorporated into the German Russian
collection of films held at GRHS Headquarters in Bismarck ND.  Copies can be
obtained from the National Archives.

There exists far too much data on these films to completely index everything.
Many of the items that were indexed will only take you to a frame of the film -
where the researcher should find more details about the person/individual.
However in some cases, there is essentially little else to be obtained on the
film other than what you see here on the file itself.

Following is a more technical description of what can be found on these films.
(other data in VOMI 742 is not included in this file).
