NOTE:

The Stumpp book, "The Emigration from Germany to Russia in the Years 1763-1862" 
contains starting on page 577 the published version of this same census.  It 
should be noted that this file only contains the first approximately 1/3 of the 
census, as that is all that is included on this film.  If we later discover the 
rest of this particular census on another DAI film or some place else we will 
update this file to include any new found information.

It should also be noted, that the researcher that uses this files data while 
also using the Stumpp book will gain more insight into this information than 
the person who uses only one or the other.

The T81 DAI film 600 contains many miscellaneous items of interest for many 
German Russian  researchers. We will add new files as we extract DAI data from 
this film.

The user is reminded, that these films as a whole will be added to the DAI film 
collection held at GRHS in Bismarck ND.

It is intended that these films be incorporated into the German Russian 
collection of films held at GRHS Headquarters in Bismarck ND.  Copies can be 
obtained from the National Archives or the Library of Congress as appropriate.

There exists far too much data on these films to completely index everything.  
Many of the items that were indexed will only take you to a frame of the film - 
where the researcher should find more details about the person/individual. How- 
ever in some cases, there is essentially little else to be obtained on the film 
other than what you see here on the file itself.

The GRHS DAI Film Indexing Project is a function of the GRHS Clearing House.  
For any persons desiring to participate in any manner, such as procurement of 
more films, translation of German and Russian, inputting of raw data into 
digital files, or anything else that comes to mind -  please contact the GRHS 
Clearing House.  We can use all of the help that volunteers are willing to
give.
