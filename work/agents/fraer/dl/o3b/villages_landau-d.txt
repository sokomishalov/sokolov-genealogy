BACKGROUND:

Nikolaev Regional Archive:  Fond 410, opis s, file 39.
Death records of Landau Roman Catholic Church, 1860-1872. Russian. 88 pages.

This data was received with a large package which arrived from Vlad Soshnikov of
RAGAS at Lincoln on 13 November 1997.  It should be noted that this set of
records is as of a result of the joint GRHS and AHSGR records retrieval project. 
Both organizations split the costs of obtaining these records.

A copy of this file has been forwarded to GRHS in Bismarck.  Both organizations
participated in the translation efforts of the many items which arrived in this
package.  However the translator of this particular file was performed by Rick
Rye of AHSGR..  The goal has been achieved to have the data translated and ready
for distribution by both GRHS and AHSGR.

By agreement of the organizations, this index has been created and being shared
here so folks can find paper copies of the translated death data file at both
organizations.

The cost for members at both organizations is $15 and for non-members $25.  The
cost for shipping and handling is $3 at AHSGR and $2.75 at GRHS.  For mailing
addresses, visit the homepages at;
          http://www.grhs.com/
          http://www.ahsgr.org/
